# src/ — Not the Live App

This React/Vite source was an earlier attempt to build the portal as a React app.
It produced blank components and was abandoned in favor of the static `index.html`.

**The live app is `index.html` in the project root — not this folder.**

This source is kept for reference and will be revived in Phase 3 when Storybook
is added as a parallel layer with real coded components.

Do not deploy or build this folder until a safe migration plan is in place.
